About APKShield

APKShield is an intelligent Android malware detection system that analyzes APK files before installation. It combines static analysis (permissions, API calls, certificates) with behavioral AI to identify threats and attribute them to known malware families.

Built with Django, Androguard, and Quark-Engine, APKShield provides fast, accurate, and explainable malware verdicts with detailed risk breakdowns.
